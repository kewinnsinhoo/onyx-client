# Kopi Client

Launcher de Minecraft de Kopi Studio para Windows, macOS y Linux.

- Login con Microsoft (premium) y cuentas offline
- Instancias por código de acceso (Vanilla, Fabric, Quilt), con sincronización de mods
- Skins en 3D, biblioteca, subir skin, capas oficiales y buscar jugadores
- Galería de capturas, creadores, avisos, consola y envío de informes
- Ajustes: cuentas + Discord, idioma (ES/CA/EN/FR), temas, memoria, ventana, Java, referidos, actualizaciones
- Actualizaciones automáticas desde GitHub Releases

Lee **GUIA.md** para ponerlo en marcha. Para probarlo en local: `npm install` y `npm start`. Pruebas: `npm test`.

PRODUCTO NO OFICIAL DE MINECRAFT. NO ESTÁ APROBADO NI ASOCIADO CON MOJANG O MICROSOFT.
